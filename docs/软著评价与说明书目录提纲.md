## 二、现有功能模块（建议写入 V1.0「已实现」）

架构：用户 → **WPF 七页** → **Bridge**（pythonnet / 训练子进程）→ **`python_core`**（权威算法）。

| 模块 | 职责 | 技术要点（说明书可写） |
|------|------|------------------------|
| 钻石检测分类 | 大图切片检测；完整模式再分类朝向 | SAHI 滑动窗口 + YOLO 定位；IoS/面积/长宽比/边缘等后处理；可选仅定位、下采样；可选可视化 / crop / 位置文件 / 联动均匀度 |
| 均匀度分析 | 对检测结果做单 tile 空间均匀度评分 | Voronoi、最近邻+Clark-Evans R、Delaunay、网格密度；CV 与 CU/DUlq；可选可视化；与检测页联动 |
| 缺陷检测 | 小图/裁剪图三分类 | 开发版 PyTorch / 机台 ONNX Runtime |
| 结果管理 | 筛选、预览、送修正、导出 | 会话结果库 |
| 误分类修正 | 人工改标并归档 | 写入 `corrections/<类>/`，支撑再训练 |
| 模型再训练 | 调用训练流程，更新分类权重 | 两阶段微调、早停、导出 ONNX；机台可锁定 |
| 设置与部署 | 配置、管理员锁、机台包 | `app_config.json`；打包 WPF + python_runtime + checkpoints + YOLO |

**检测模型（运行依赖，非独创主张核心）**：YOLO 权重（如 `detect_weights/best.pt`），经 Ultralytics 等推理栈加载。  
**分类模型（运行依赖 + 自有训练流程）**：EfficientNetV2-S，三类 `棱边朝上` / `点朝上` / `面朝上`；Letterbox 与训练一致；机台 ONNX。

**明确不写入 V1.0「已实现」的**：整盘 tile 坐标合并、真实圆盘边界替代凸包、盘级统一评分、磨损/出露高度等 3D 计量（见第四节路线图）。

## 三、独创性与第三方边界（交件表述要点）

### 3.1 建议主张的独创表达（示例表述方向）

1. **面向 CMP 修正盘质检的端到端软件流程**：大图检测 → 朝向分类 → 结果管理 → 误分类归档 → 再训练更新 → 机台部署。  
2. **大图检测工程化流水线**：切片参数与重叠约束、后处理链、可选输出物与配置持久化。  
3. **分类工程化**：训练/推理一致的 Letterbox 预处理、有效类决策、批量推理与耗时统计、ONNX 机台路径。  
4. **均匀度业务模块**：点模式多指标并行输出、友好百分比、落盘契约与可视化（单 tile）。  
5. **主动学习闭环**：修正样本目录约定与再训练入口（软件流程独创性较强）。  
6. **桌面与算法解耦架构**：C# WPF / MVVM + Python 算法权威实现 + Bridge。

### 3.2 建议如实披露的第三方 / 开源成分

| 类别 | 示例 | 表述建议 |
|------|------|----------|
| UI 框架 | .NET / WPF | 基于通用框架开发 |
| 检测框架与模型族 | Ultralytics、YOLO | 调用第三方检测框架与权重 |
| 分类骨干与推理 | torchvision EfficientNetV2、ONNX Runtime、PyTorch | 基于公开骨干微调/导出；推理引擎为第三方 |
| 数值与视觉库 | OpenCV、NumPy、SciPy、shapely 等 | 通用库 |
| 点模式经典指标 | Voronoi、Clark-Evans、Delaunay、Christiansen CU 等 | 采用公开方法组合实现业务模块 |

### 3.3 不宜作为软著「权利核心」的内容

- 单纯准确率 / Macro-F1 等指标数字  
- 「自研 YOLO / 自研 EfficientNet 结构」类表述（除非另有专利且结构确属自研）  
- 尚未实现的盘级 / 3D 磨损能力

## 四、围绕 CMP 修正盘的可扩展应用（路线图，非 V1.0 已实现）

结合修正盘（pad conditioner）质检常见需求与本仓库已有能力，建议产品扩展优先级如下（与业务确认一致）：

| 优先级 | 方向 | 说明 | 与现状关系 |
|--------|------|------|------------|
| **P1** | 盘级拼接 + 圆盘标定/真实边界 + 分区统计 | tile→整盘坐标；圆心半径；内中外环等 | 文档已标二期；补齐 Disk 场景 |
| **P2** | 盘级朝向/密度质量报告与阈值告警 | 点/棱边/面占比、疏密、漏排扎堆等看板 | 建立在 P1 与现有分类/均匀度之上 |
| **P3** | 缺陷类独立统计与再训练 | 断钻/局部破损等与朝向解耦；缺陷率报表 | 历史类别与闭环可衔接 |
| **P4** | 批次履历、OK/NG 规则、导出/MES 对接 | 盘号、批次、判定、车间集成 | 偏软件与信息化，软著后续版本易写 |
| **P5**（单列） | 磨损、出露高度、共面活性尖等 | 常需 3D/轮廓仪或专用计量 | **需传感/算法升级**；勿写入 V1.0 已具备 |

其它可选（评价备忘，不排进当前主路径）：干摩擦/划痕代理诊断接口、配方/盘种多模型管理、难例自动挖掘增强主动学习等。
