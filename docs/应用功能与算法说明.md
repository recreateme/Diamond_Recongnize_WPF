## 1. 概述

系统做四类事：

1. **大图检测 + 朝向分类**：SAHI 切片 + YOLO 定位，再对每颗钻石做有效三类分类。  
2. **单图/批量小图分类**：缺陷检测页直接对裁剪图或小图推理。  
3. **均匀度评分**：对检测结果做点模式空间统计，只出连续分数（可可视化）。  
4. **主动学习闭环**：误分类归档 → 再训练 → 热加载/更新机台 `checkpoints/`。

```
用户 → WPF（七页）
         ↓ Bridge（pythonnet / 训练子进程）
    python_core（推理 / SAHI / 均匀度 / 训练）
         ↓
checkpoints/ · detect_weights/ · app_config.json
```

**类别约定（应用层）**

| 层 | 约定 |
|----|------|
| 模型输出 | 仍为 5 类：`局部破损`、`断钻`、`棱边朝上`、`点朝上`、`面朝上` |
| 应用有效类 | 仅后三类；排除前两类后做 softmax argmax |
| 不使用 | `class_thresholds.json` 逐类阈值 |

实现：`python_core/inference_common.py`。

## 2. 功能页

| 快捷键 | 页面 | 主要职责 |
|--------|------|----------|
| Ctrl+1 | 钻石检测分类 | 大图 SAHI+YOLO；可选仅定位；可选跑完算均匀度 |
| Ctrl+2 | 均匀度分析 | 对产品输出根批量/子集打分与可视化 |
| Ctrl+3 | 缺陷检测 | 单张/批量小图三分类 |
| Ctrl+4 | 结果管理 | 筛选、预览、送修正、导出 |
| Ctrl+5 | 误分类修正 | 待修正队列归档到 `corrections/<类>/` |
| Ctrl+6 | 模型再训练 | 调 `train.py`（机台只读） |
| Ctrl+7 | 设置 | 分类/切片/`app_config`（机台默认管理员锁） |

### 2.1 钻石检测分类

| 项 | 说明 |
|----|------|
| 做什么 | 对约 5120×5120 tile（或整盘切图）做切片检测；完整模式再分类朝向 |
| 模式 | **完整模式**（检测+分类）；**仅检测定位**（只要坐标，可下采样） |
| 输入 | 选文件或文件夹图像 |
| 输出根 | 默认 `sahi_output/`（可改）；每图一子目录 |
| 完整模式产物 | `detect_boxes.json/csv`（含 `det_conf`、`defect_class`、`defect_conf`）；可选 `visualization_classified.jpg`；根 `summary.csv` |
| 仅检测产物 | 坐标文件（含 `det_conf`）；可选 `visualization_detection.jpg`；**不写** `summary.csv` |
| 0 目标 | 子目录名 `{stem}_无目标` |
| **均匀度联动** | 输出选项勾选「完成后计算均匀度」（**默认关**，仅完整模式可用）；跑完写各子目录 `uniformity_scores.json` 与根 `uniformity_summary.csv`，**不自动跳转**均匀度页 |
| 算法模块 | `python_core/sahi_detector.py` + 分类引擎 |
| 配置 | 设置页 SAHI 段 / `app_config.json` 的 `sahi_*`、`yolo_path` |

### 2.2 均匀度分析（独立页）

| 项 | 说明 |
|----|------|
| 做什么 | 对**已有检测输出根**（如 576 子图产品包）做单 tile 均匀度评分 |
| 输入 | 选产品输出根 → **扫描** → 勾选子图（默认全选） |
| 认文件 | 每子目录优先 `detect_boxes.json`，否则旧版 `result.json` |
| 过滤 | `det_conf ≥ uniformity_conf_threshold`（可改，写入配置）；仅三类朝向；旧 JSON 无 `det_conf` 时跳过置信度过滤并标记 `conf_filter=skipped` |
| 分数落盘 | `{子图}/uniformity_scores.json`；根 `uniformity_summary.csv`（本次勾选行，覆盖） |
| 可视化 | 点选结果行按需生成 `{子图}/uniformity_vis.jpg`（底图+点+凸包+网格热力）；批量可勾「同时生成可视化」（**默认关**） |
| 不做 | 均匀/不均二分类；盘级合并坐标评分 |
| 算法模块 | `python_core/diamond_uniformity.py` · Bridge `IUniformityAnalyzer` |

与检测页联动的差异：独立页可处理历史/`result.json` 包、可勾选子集与可视化；联动默认只出分、不出图。

### 2.3 缺陷检测

| 项 | 说明 |
|----|------|
| 做什么 | 对单张或批量**小图**做三分类（非 SAHI 大图流水线） |
| 输出 | 内存结果表；可送结果管理 / 导出 |
| 算法 | `inference_engine.py`（开发）/ `inference_engine_onnx.py`（机台） |

### 2.4 结果管理

筛选类别与置信度、预览、送修正、导出 CSV/按类文件夹。数据来自缺陷检测会话的 `ResultStore`。

### 2.5 误分类修正

待修正队列；点正确类别归档到 `corrections/<有效类>/`；可从文件夹导入待标注样本。

### 2.6 模型再训练

| 项 | 说明 |
|----|------|
| 开发版 | 解锁后调 `python_core/train.py`；可带 `corrections/` 为 `--extra_data_dirs`；成功后可热加载 |
| 机台版 | **只读**，不在机台上训练 |
| UI 常用项 | 见第 4.3 节 |

### 2.7 设置

分类模型路径、GPU、SAHI/YOLO 参数、输出目录等写入 `app_config.json`。机台默认锁定，需管理员口令。

## 3. 算法摘要

### 3.1 大图检测（SAHI + YOLO）

- 大图按 `sahi_slice_size` / `sahi_overlap` 切片，YOLO 检出框，再合并与后处理（IoS、面积比、长宽比、边缘过滤等）。  
- 完整模式：对每个框裁剪送分类引擎，得到 `defect_class` / `defect_conf`。  
- 细节与漏检优化路线：[钻石检测低分辨率漏检优化方案.md](钻石检测低分辨率漏检优化方案.md)。

### 3.2 朝向分类（有效三类）

- 骨干：训练侧 EfficientNet 等（见 `train.py`）；机台推理优先 ONNX Runtime。  
- 决策：排除「局部破损」「断钻」后，在三类内 argmax；`all_scores` 仅含三类。  
- 权威实现：`inference_common.py`（勿在 C# 重写 softmax/有效类逻辑）。

### 3.3 均匀度（单 tile 点模式）

对过滤后的钻石中心做空间统计，**只出连续分数**。完整设计见 [钻石均匀度评分模块说明.md](钻石均匀度评分模块说明.md)；实现：`python_core/diamond_uniformity.py`。

| 指标 | 含义（直觉） | 分数方向（经验） |
|------|----------------|------------------|
| **Voronoi 面积 CV**（raw / normalized） | 各点胞元面积离散度；normalized 用框面积归一 | CV 越低通常越均匀 |
| **最近邻距离 CV** + **Clark-Evans R** | 点距离散度；R 相对完全随机的期望邻距 | CV 越低、R 越大（>1 偏规则）通常越均匀；normalized gap 的 CV 可能为负 |
| **Delaunay 边长 CV** | 三角网边长离散度 | CV 越低通常越均匀 |
| **网格密度 CV** | 凸包外接矩形切 n×n 格后的密度离散度 | 抓「大片偏疏/偏密」；CV 越低通常越匀 |

边界：用检测点**凸包**作分析区域（非整图矩形）。可视化热力对应网格密度法。

## 4. 模型与配置

### 4.1 权重与目录

| 路径 | 用途 |
|------|------|
| `checkpoints/model.onnx`（及 `.data`） | 机台分类（必需） |
| `checkpoints/best_model.pt` | 开发版 PyTorch 可选 |
| `checkpoints/class_map.json` | 类别名（模型 5 类） |
| `detect_weights/best.pt` | YOLO 检测（钻石检测页 / 打包必需） |
| `corrections/<类>/` | 人工归档样本，再训练额外数据 |
| `app_config.json` | 运行时配置 |

### 4.2 `app_config.json` 关键键

| 键 | 默认/机台习惯 | 说明 |
|----|----------------|------|
| `onnx_path` | `checkpoints/model.onnx` | 分类 ONNX |
| `pt_path` | 开发有、机台常空 | PyTorch 权重 |
| `use_gpu` | `true` | 分类是否用 GPU |
| `yolo_path` | 机台 `detect_weights/best.pt` | YOLO 权重 |
| `sahi_device` | `auto` | 检测设备 |
| `sahi_slice_size` | `1280` | 切片边长 |
| `sahi_overlap` | `0.2` | 切片重叠 |
| `sahi_det_conf` | `0.35` | YOLO 检测置信度 |
| `sahi_batch_size` | 开发 8 / 机台模板常 16 | 检测 batch |
| `sahi_output_dir` | `sahi_output` | 检测输出根 |
| `sahi_ios_thresh` 等 | 见设置页 | 后处理 |
| `uniformity_conf_threshold` | `0.25` | 均匀度用 `det_conf` 过滤 |
| `data_dir` / `corrections_dir` | `data` / `corrections` | 训练与归档 |
| `enable_local_diagnostics` | `false` | 本机 `logs/diag.jsonl` |

完整白名单与输出文件约定：[CONTRACTS.md](CONTRACTS.md)。

### 4.3 再训练超参（开发版 UI ↔ `train.py`）

再训练页会把下列参数传给 `python_core/train.py`（存在 `corrections/` 时自动加 `--extra_data_dirs`）：

| UI / 参数 | 再训练页默认 | `train.py` CLI 默认 | 说明 |
|-----------|--------------|---------------------|------|
| `--img_size` | 128 | 128 | 输入边长 |
| `--batch_size` | 16 | 32 | 批大小 |
| `--epochs_phase1` | 10 | 5 | 阶段 1（多冻骨干） |
| `--epochs_phase2` | 25 | 20 | 阶段 2 微调 |
| `--data_dir` | 配置 `data_dir` | `data` | 主训练集 |
| `--save_dir` | `checkpoints` | `checkpoints` | 输出权重/ONNX |
| `--extra_data_dirs` | `corrections`（若有） | 空 | 额外数据根 |
| `--finetune` | 按页逻辑 | 关 | 微调模式（见页内选项） |

其它常用 CLI（一般不在 UI 暴露，需要时命令行跑 `train.py`）：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--val_ratio` | 0.15 | 验证集比例 |
| `--lr_phase1` / `--lr_phase2` | 1e-3 / 1e-4 | 两阶段学习率 |
| `--label_smooth` | 0.1 | 标签平滑 |
| `--patience` | 8 | 早停 |
| `--use_focal_loss` / `--focal_gamma` | 开 / 2.0 | Focal Loss |
| `--use_class_weight` | 开 | 类别权重 |
| `--amp` | 开 | 混合精度 |
| `--pretrained` | 开 | ImageNet 预训练 |
| `--resume` | 空 | 断点权重路径 |

权威参数表以 `python train.py -h` 为准。

## 5. 输入 / 输出速查

### 5.1 检测完整模式（每图子目录）

`detect_boxes.json` · `detect_boxes.csv` · 可选 `visualization_classified.jpg` · 可选均匀度 `uniformity_scores.json` / `uniformity_vis.jpg`

根目录：`summary.csv` · 可选 `uniformity_summary.csv`

### 5.2 旧产品包（如 576 tile 的 `result.json`）

均匀度页可直接扫描：优先 boxes，否则 `result.json`。无需先转新格式。

### 5.3 环境变量

| 变量 | 含义 |
|------|------|
| `DEFECTS_DEPLOY=1` | 机台模式（ONNX） |
| `DIAMOND_PYTHON_HOME` / `DIAMOND_PYTHON_DLL` | Python 运行时 |
| `DEFECTS_VERIFY=1` | 无界面验收 |
