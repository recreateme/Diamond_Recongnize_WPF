# 功能验收清单（WPF）

在开发机或机台包上逐项勾选。算法应对齐原 `defect_detect` 行为。

## A. 启动与模式

- [ ] 开发版启动，状态栏显示模型加载成功（PyTorch 或 ONNX）
- [ ] `DEFECTS_DEPLOY=1` 启动，标题/模式为机台，分类为 ONNX
- [ ] `--verify` / `验收_verify.bat` 退出码 0
- [ ] 无 GPU 或强制 CPU 时仍可分类（可有警告）

## B. 设置

- [ ] 机台设置默认锁定；错误密码拒绝；正确密码可编辑
- [ ] 保存 `app_config.json` 后重新加载模型生效
- [ ] 切片参数字段完整（YOLO、slice、overlap、长宽比等）

## C. 缺陷检测

- [ ] 单张：拖放/选图 → 类别、置信度、得分条；阈值提示（若有）
- [ ] 同路径重复检测 upsert，不新增行
- [ ] 批量：进度、停止、结果表；可跳转结果管理
- [ ] 导出分类结果按类分文件夹

## D. 结果管理

- [ ] 类别筛选 + 置信度上限 + 置信度排序
- [ ] 送修正后本页消失，修正页角标增加
- [ ] 点击正确类别归档到 `corrections/<类>/`
- [ ] 导出 CSV / 导出勾选分类图

## E. 误分类修正

- [ ] 列表显示待修正项；大图预览
- [ ] 点类别立即归档并移出队列
- [ ] 「选择文件夹」导入待标注样本

## F. 再训练（开发机）

- [ ] 锁定时不可训练；解锁后可跑 `train.py`
- [ ] 日志实时输出；停止可用
- [ ] 成功后「应用新模型」热加载
- [ ] 存在 `corrections/` 时命令含 `--extra_data_dirs`

## G. 钻石检测分类（SAHI）

- [ ] YOLO 路径有效时可处理大图
- [ ] 输出含可视化、crops、json；根目录有 `summary.csv`
- [ ] 进度/停止；完成后可打开输出目录
- [ ] 统计表钻石数与缺陷分布合理

## H. 机台包

- [ ] `build_deploy_wpf.ps1` 产出完整目录
- [ ] 整包复制后 `验收_verify.bat` 通过
- [ ] 仅覆盖 `checkpoints/` 可更新分类模型
