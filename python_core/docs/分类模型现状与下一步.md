## 2. 全量 corrections 评测（n=2793）

数据根：`D:\迅雷下载\corrections`（面 2356 / 棱边 369 / 点 68，偏斜极大）。  
完整对比见 `checkpoints/eval_full_corrections/`。

| 指标 | 旧正式（晋升前） | **现行正式** |
|------|------------------|--------------|
| Acc | 0.735 | **0.834** |
| Macro-F1 | 0.512 | **0.655** |
| Weighted-F1 | 0.776 | **0.867** |

### 逐类（现行正式）

| 类别 | Precision | Recall | F1 | support |
|------|-----------|--------|-----|---------|
| 棱边朝上 | 0.692 | 0.854 | **0.765** | 369 |
| 点朝上 | 0.178 | 0.941 | **0.300** | 68 |
| 面朝上 | 0.985 | 0.828 | **0.900** | 2356 |

相对旧正式：三类 F1 均提升（棱边 0.49→0.76，点 0.21→0.30，面 0.84→0.90）。

### 解读

- **Acc / Weighted-F1** 受面朝上占比拉动，不能单独作为「≥85%」门禁。  
- **Macro-F1 0.655** 距目标 0.85 仍有明显差距。  
- **点朝上**：召回很高（≈0.94），精确率很低（≈0.18）→ 大量其它类被误判为点，是 Macro-F1 主瓶颈。  
- 全量集可能仍含歧义标注；指标需结合抽检理解。

## 3. 下一步建议（精度优先）

1. **清洗 / 补点朝上清晰样本**（优先于继续堆面朝上）：提高点类精确率。  
2. **人工复核易混样本**（面↔点、棱边↔点），从训练池剔除歧义或单独「疑难」目录不进 train。  
3. **再训协议**：继续「少数类全留 + 多数类欠采样」；可试略提高点类占比（如 2:2:1.5）或对点类更强增强，门禁用 **Macro-F1 + 点 F1/Precision**。  
4. **评测固定**：保留一份分层固定测试集（三类都够数），避免只看全量偏斜 Acc。  
5. 速度向优化仍见 [分类推理速度优化建议.md](分类推理速度优化建议.md)；精度未达标前勿用轻骨干换精度。
