相对晋升前：Acc / Macro-F1 / 点 F1 均略升；**点朝上 Precision 仍很低（≈0.16）**，大量面/棱边被误判为点，是 Macro-F1 上不去的主因。

### 解读

- 全量集面朝上占约 **87%**，Acc / Weighted-F1 会被多数类拉动，**不能单独作门禁**。  
- Macro-F1 ≈ **0.63**，距「综合 ≥0.85」仍远。  
- 点朝上：**高召回、低精确率** → 下一轮必须针对易混负样本与点类质量，而不是继续堆面朝上。

## 3. 下一步建议计划

### P0 — 数据质量（优先）

1. **人工复核面↔点、棱边↔点易混图**  
   - 从全量 corrections 中按混淆矩阵抽检（真值面/棱边却被判成点的样本）。  
   - 歧义样本移出训练池或进「疑难」目录，**不参与正式 train**。  
2. **补清晰点朝上**（姿态明确、光照正常），目标点类清晰样本继续增加；避免只增加模糊/截断点图。  
3. **固定分层测试集**：每类预留足够张数（建议点 ≥30），只评测不训练，避免只看偏斜全量 Acc。

### P1 — 再训协议调整

4. 保持「点全留 + 多数类欠采样」；在清洗后可试 **面:棱边:点 = 1.5:1.5:1**（提高点相对占比）。  
5. 门禁改为同时看：**全量/固定测集 Macro-F1** + **点 Precision / F1**（例如点 Precision 先冲 ≥0.35）。  
6. 训练侧：若再出现 `loss nan`，降低 lr、检查坏图/极值增强，或关掉 AMP 做对照。  
7. 暂不换轻骨干、不上 INT8；精度未稳前速度优化另见 [分类推理速度优化建议.md](分类推理速度优化建议.md)。

### P2 — 工程与发布

8. 达标后再晋升正式权重并打包；未达标则保留旁路产物对比。  
9. 机台包更新后用固定小批图回归 `classify_ms` 与抽检混淆，避免只看离线 CSV。

### 不建议

- 用全量 5152 无欠采样直接再训冲 Acc  
- 为提高 Acc 继续大量加入面朝上  
- 在点 Precision 未改善前宣称「正确率已达 85%」
