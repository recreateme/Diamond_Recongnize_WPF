# 分类推理速度优化建议

> 基于 ECOA 批测与 GPU 诊断（约 10 张 5120 原图、EfficientNetV2-S@256、SAHI 切片检测）。  
> 结论：**瓶颈在分类推理（约 85%）**；检测约 15%；预处理可忽略。  
> 现行正式权重：`checkpoints/`（EfficientNetV2-S，Letterbox，val Macro-F1 ≈ 0.82）。

---

## 1. 已确认事实（勿重复踩坑）

| 项 | 结论 |
|----|------|
| GPU | ORT CUDA + YOLO CUDA 均可用（RTX 5060 Laptop / sm_120）；勿再怀疑「其实在 CPU」 |
| 分类 batch | 代码常量 `_DEFAULT_BATCH_GPU=64`（`inference_engine_onnx.py`）可用，约 221 ms/颗；**128 会 OOM**，当前机型勿再试 128 |
| `sahi_batch_size` | 仅控制 **YOLO 切片检测** batch（配置里常 8–16），与分类 batch 无关 |
| 预处理 | Letterbox + OpenCV 批量路径已足够快，不是主矛盾 |
| 检测切片重叠 | 有效重叠硬上限 **280px**；默认 `slice=1248` / `overlap≈0.2244`（5120→5×5） |

典型拆分（单图量级）：检测 ~3–5s，分类 ~20–30s（数百颗时）。

---

## 2. 建议尝试顺序（优先收益）

### P0 — 分类加速（最大头）

1. **ONNX INT8 / TensorRT EP**  
   - 在保持 Macro-F1 可接受的前提下做量化或换 TensorRT Execution Provider。  
   - 验收：同图 `classify_ms`、`ms_per_diamond` 与 val Macro-F1。

2. **更轻量分类骨干（需重训）**  
   - 候选：EfficientNet-B0、MobileNetV3 等；仍用 Letterbox + 当前校正集协议。  
   - 门禁建议：val Macro-F1 ≥ 0.78（或相对现网跌幅可控），再比速度。

3. **跨图分类批合并（工程）**  
   - 批处理时多图 crop 拼成更大有效 batch（仍 ≤64），提高 GPU 利用率。  
   - 注意显存峰值与失败回退到 64。

### P1 — 检测与流水线

4. **SAHI 检测 `batch` / FP16**  
   - 在 `sahi_detector` / Ultralytics 侧提高推理 batch 或半精度；对比 `detect_ms` 与漏检。

5. **批处理默认关可视化与 crop 落盘**  
   - UI/配置：批量跑只写 `summary.csv` + 必要 json；`crop/`、全图标注图按需开启。

6. **检测与分类重叠（流水线）**  
   - 图 N 分类与图 N+1 检测并行（双队列）；收益取决于 GPU 是否仍被分类占满。

### P2 — 可选

7. 分类输入 224（需重训/重导）  
8. 低置信度跳过二次精分 / 级联小模型  
9. 多进程多卡（机台有第二块 GPU 时）

---

## 3. 不建议再做

- 把分类 `_DEFAULT_BATCH_GPU` 提到 **128**（本机 OOM）  
- 再花大力气抠预处理（占比极低）  
- 在未量化前指望「再调一点分类 batch」解决分类耗时

---

## 4. 验收口径

批测后看 `summary.csv`：

- `detect_ms` / `classify_ms` / `ms_per_diamond`  
- 总耗时与颗数  
- 精度：校正集或抽检 Macro-F1 / 混淆矩阵  

建议每次只改一个变量，保留对比行（基线 batch=64、当前 ONNX）。

---

## 5. 相关代码入口

| 模块 | 说明 |
|------|------|
| `python_core/sahi_detector.py` | 切片网格、重叠上限、检测 batch、耗时拆分 |
| `python_core/inference_engine_onnx.py` | 机台 ORT 分类；`_DEFAULT_BATCH_GPU=64` |
| `python_core/inference_common.py` | Letterbox / 批量预处理 |
| `app_config.json` | `sahi_slice_size`、`sahi_overlap`、`sahi_batch_size`（检测） |

切片配置默认：`sahi_slice_size=1248`，`sahi_overlap=0.2244`；分类 GPU batch 默认 64（代码常量，非配置项）。
